# CUDA Parallel Programming Tutorial Series (PyCUDA)

## 📌 Overview

This repository contains a structured learning path for **GPU Parallel Programming using CUDA (via PyCUDA)**.  
It covers fundamental to intermediate GPU concepts with real performance comparisons between:

- CPU (NumPy)
- GPU (PyCUDA CUDA kernels)

The tutorials also include:

- Grid & Block indexing
- Matrix multiplication
- Shared memory optimization
- Image processing (medical imaging style)
